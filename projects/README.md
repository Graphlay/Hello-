# projects

One folder per video being worked on.

Suggested layout for each project:

```
projects/2026-11-16_project-name/
├── brief.md        # goal, platform, length, notes
├── edit-notes.md   # cut decisions, timestamps, feedback rounds
├── working/        # proxies, intermediate renders, project files
└── captions/       # .srt / .vtt files
```

Raw footage stays in `raw-videos/`; finished files go to `exports/`.
