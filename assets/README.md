# assets

Reusable building blocks for any edit.

| Folder    | What goes there                                   |
|-----------|---------------------------------------------------|
| `music/`  | Background tracks (licensed / royalty-free only)  |
| `sfx/`    | Sound effects: whooshes, pops, risers, clicks     |
| `images/` | Stills, overlays, stickers, textures, b-roll pics |
| `fonts/`  | Font files (.ttf / .otf) used in captions & titles |
